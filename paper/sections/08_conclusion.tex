\section{Conclusion}
\label{sec:conclusion}

This study integrates quantitative alpha context and Vietnamese-language sentiment into a five-role LLM framework for Vietnamese-equity trading research. It specifies the single-asset factor transformations, separate sentiment construction, shared report composition and forecast-to-account action mapping. The common-support evaluation compares the full input bundle with simple numerical controls and complementary repeated component/placebo panels.

On 102 market units, Full balanced accuracy is \FullBA\% versus Base \BaseBA\%, while a price-only logistic comparator reaches \LogisticPriceBA\%. The Full--Base difference accompanies fewer false LONG forecasts and the same seven captured UP outcomes. Full's mean separate-account net return is \FullReturn\%, compared with \BaseReturn\% for Base. Quantitative integration therefore changes recorded decisions, but this study does not establish stable predictive superiority, causal component value or deployable profitability. Native row-wise factor noncausality, historical news/domain uncertainty and limited calendar/repeat support constrain interpretation. A prospective evaluation with corrected causal construction and independent domain/execution validation is needed to test generalisation.
