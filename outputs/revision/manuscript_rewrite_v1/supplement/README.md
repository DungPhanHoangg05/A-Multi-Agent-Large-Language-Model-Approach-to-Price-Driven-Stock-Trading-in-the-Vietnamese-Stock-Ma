# Scientific companion tables

These local companions accompany the historical manuscript rewrite. They export frozen results without new predictions, baseline fits, model calls or statistical resampling. Public distribution rights and a persistent identifier remain pending; this directory is not a published archive.

| Group | Files and support |
|---|---|
| S1 | [Classification](S1_classification.csv): 144 all-102 rows, including nine pooled, 81 symbol and54 block rows. [Per-class](S1_per_class.csv):288 rows, including162 symbol/class rows. [Macro](S1_macro.csv):45 metric rows with planned/defined denominators. Hold is an account strategy, not a tenth classifier. |
| S2 | [Executions](S2_executions.csv):21 rows; [contrasts](S2_contrasts.csv):48 contrast/metric rows; [disagreements](S2_disagreement.csv):63 unit/variant rows. Upstream and factorial supports remain separate. |
| S3 | [Numeric metrics](S3_test_metrics.json), [all20 random trials and dispersion](S3_random_trials.json), and [all23 hypotheses](S3_family.json). These use a separate train-fit numeric path, not a native LLM selector ablation. |
| S4 | [Calendar](S4_calendar.csv):972 prediction cells corresponding to108 market cells,102 eligible and six excluded. [HAC](S4_HAC.csv):six rows; [block sensitivity](S4_block_sensitivity.csv):144 rows; [regimes](S4_regimes.json) and [dependence/cohorts](S4_dependence.json) retain all saved strata and structural diagnostics. |

Percentages/percentage points and raw MCC are distinguished in the article. Source CSV fractions and full precision are preserved here; undefined CSV values remain `NA`, JSON metrics retain `null`. Rows, symbols, repeats and resamples are not independent replications.

Full source expressions,80 retained/21 excluded entries and five custom handlers remain in the [registry](../../alpha_registry_v1/registry.json), with [native causal counterexamples](../../alpha_contract_v1/leakage.json), [selection frequency](../../alpha_selection_v1/aggregate.json) and [IC-sign transitions](../../alpha_selection_v1/transitions.json). Model/input/provenance, raw calls, software/runtime and execution details are in their separately versioned repository releases, not duplicated as scientific article appendices.

Main and submission sources share the same scientific content. Author metadata, publication route, rights/PID and final PDF locators require their later confirmation/QA steps. These companions do not close reviewer comments or certify profitability, PIT/domain validity, row-wise native causality or immutable hosted weights. Confidential review material is not included.
